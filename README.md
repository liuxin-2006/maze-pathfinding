# maze-pathfinding

Java 实现的迷宫生成与自动寻路系统 —— 数据结构课程设计（2026.05）

## 功能

- **迷宫生成**：递归回溯法（Recursive Backtracker）生成「完美迷宫」，通路无环，任意两格之间恰有一条通路
- **路径求解**：BFS 广度优先搜索求 0/1 网格上的最短路径
- **可视化**：Swing 界面实时演示迷宫生成与寻路过程
- **随机可复现**：支持固定随机种子，同一尺寸下可复现同一张迷宫

## 技术实现

### 迷宫生成（MazeGenerator）

采用递归回溯法，核心思路是「先全墙、再挖洞」：

1. 网格初始化为全 1（墙），`0 = 通路，1 = 墙`
2. 从内区某个奇数「房间」格出发，以步长 2 向四个方向移动
3. 打通当前格与目标格之间的那面墙（`g[r + dr/2][c + dc/2] = 0`），递归进入目标格
4. 每个节点访问前用 `Collections.shuffle(dirs, rng)` 打乱方向，保证生成结果随机
5. 递归结束后统一封边 `sealBorder`，确保四周是完整墙体

尺寸处理：`normalizeSize` 强制总尺寸为奇数且不小于 5；`snappedRoomCell` / `clampOddInner` 把任意坐标钳制到内区的奇数「房间」格，保证挖洞起点合法。

### 路径求解（MazeSolver）

BFS 逐层扩展求最短路：

- `ArrayDeque` 维护队列，`vis` 布尔数组在**入队时**即置位，避免同一格重复入队
- 二维父指针表 `pr` / `pc` 记录每个节点的来源，抵达终点后沿指针回溯到起点，再由 `Collections.reverse` 反转为「起点 → 终点」
- 起点或终点越界、落在墙格、完全不可达时统一返回空表，不使用异常控制流程
- 时间复杂度 O(V+E)，空间复杂度 O(V+E)

由于迷宫是「完美迷宫」，任意两格之间只有一条通路，因此 BFS 找到的路径即为唯一解，同时也是最短解。
